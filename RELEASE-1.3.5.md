# Атлас ЦМПОН 1.3.5 · Ввод имени на телефоне

17 октября 2026. Срочное исправление формы входа в Цитадель и смены позывного.

При появлении экранной клавиатуры браузер меняет высоту видимой области. Игра заново создавала содержимое окна, удаляла активное поле и теряла фокус. На телефоне это мешало ввести имя. Фоновое обновление профиля могло также сбросить редактирование позывного.

- Изменение высоты больше не пересоздаёт форму входа. Поле, фокус и выделение текста сохраняются.
- Перерисовка активной формы откладывается, пока пользователь вводит имя или позывной; фоновые сообщения обновляются отдельно.
- Для переименования добавлен отдельный черновик в памяти. Ввод, автозаполнение и ошибка отправки не возвращают старое имя. Отмена оставляет сохранённое имя прежним.
- Ориентация определяется по экрану; при отсутствии API изменение только высоты не считается поворотом телефона. Настоящий поворот во время полёта по-прежнему ставит игру на паузу.
- Карточки учебных разборов продолжают пересчитывать страницы при изменении доступного места.

Проверки: регрессия с реальным отключением модельных DOM-узлов при замене innerHTML, серии событий виртуальной клавиатуры, сохранение фокуса и выделения, кириллица, emoji, составной ввод, автозаполнение, поворот и переход через адаптивную границу, отправка формы, повтор после ошибки, смена/отмена имени, вход и восстановление турнира, очередь синхронизации, мобильное управление и сборка сайта. Исходная версия 1.3.4 не проходит первый сценарий; 1.3.5 проходит.

Это автоматические проверки модели DOM и производственного кода. Физический iPhone и Safari в этой среде недоступны. Полные боевые кампании и визуальные проверки релиза 1.3.4 не повторялись: игровые правила, содержание кейсов, CSS и данные атласа побайтно сохранены. Протокол кампании остаётся 1.3.0; сервер, настройки Кубка и результаты участников не менялись. Проверочные запросы выполнялись только к локальной имитации API.

Обновление применяется после обычной перезагрузки страницы. Очищать данные браузера не нужно.
