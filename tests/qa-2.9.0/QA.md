## Метод

Конвои запускаются с определённым начальным оснащением; дальше оператор
передаёт обычные команды с задержкой реакции 0,3 с. Здоровье, позиции,
боезапас и условие победы во время этих 18 полётов не подменяются.
Изолированная проверка столкновения отдельно задаёт контактную позицию,
чтобы проверить урон и складывание конечности после импульса.

Старые сохранения получены из исходников коммита `d278bf1`. После загрузки
в 2.9 они получают те же команды, что исходный движок; сравнивается полное
упакованное состояние. Текущий конвой без `warp290` не получает новых встреч.

Визуальные PNG и пары «до/после» рисуются настоящими функциями игры в Node VM
и native Canvas. Это кадры отдельных сцен, а не доказательство прохождения.
Ветвь подробной геометрии проверяется отдельно с признаком WebGL, но это
не проверка реального GPU. В облачном браузере работал совместимый Canvas.

Браузерная QA-страница использует сохранения только в памяти, не отправляет
рейтинг и аналитику. Ускорение 600 шагов на кадр относится к симуляции.
Для осмотра сцены QA-адаптер останавливает дальнейшие шаги на заданном
времени, не меняя статус игры и не накрывая её экраном паузы.

В 640×360 и 390×780 проверены видимые конечности, предупреждение, отсутствие
горизонтального переполнения. Подсказка ракет скрывается на время основного
уведомления; предупреждение о существе расположено ниже. Кнопки управления
не менялись. Дополнительно осмотрены база с разрушениями и Рой.

Физические телефоны, WebGL на пользовательском устройстве и человеческий
баланс не измерялись. Времена native Canvas в visual.json не являются FPS
телефона. В наиболее тяжёлом программном конвое один из двух сохранившихся
транспортов закончил с 1 HP; успешный автопилот не доказывает лёгкость миссии.

## Повторение

```sh
node tests/convoy290-regression.cjs
node tests/detail290-qa.cjs
node tests/release290-regression.cjs
node tests/runtime193-regression.cjs --report tests/qa-2.9.0/runtime.json
python scripts/prepare-release-290.py
```

HTTP-сверка опубликованной версии выполняется отдельно:
`python tests/verify-production290.py --commit COMMIT_SHA`.
