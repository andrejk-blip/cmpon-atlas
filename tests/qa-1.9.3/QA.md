# Цитадель ЦСИИ 1.9.3 — QA и расследование зависания

Дата: 19.10.2026. Публичная игра: https://andrejk-blip.github.io/cmpon-atlas/
Код диагностики: `2ac210486fd9ec15e33a6a460c33399c5e44f675`, сборка runtime `193r2`.

## Вывод и первопричина

Подтверждено переполнение стека из-за взаимного оборачивания `engine.emit` звуковым и комиксным модулями. SFX временно устанавливал `scoped`; comic принимал его за новый постоянный обработчик. Проверка восстановления SFX (`engine.emit === scoped`) переставала выполняться, и каждый шаг оставлял новую пару обёрток. Любое последующее событие проходило растущую рекурсивную цепочку. Исключение происходило до последнего `requestAnimationFrame` в старом `arcadeFrame`: игровой кадр больше не планировался. DOM-интерфейс и уже запущенный Web Audio продолжали жить независимо.

На момент начала работы `main` и публичный сайт уже содержали начальный патч 1.9.3 (`c5e5a51`), хотя в задании указана 1.9.2. Поэтому отказ воспроизводился на изолированной копии настоящего публичного входа с прежними SFX/comic 1.9.1 и без нового runtime. В Chrome: **2 537 игровых шагов, 2 536 замен emit, RangeError, RAF pending = 0**, звук продолжал работать. В Node: отказ после 3 700 шагов. Стек из консоли: [browser-console-baseline.json](browser-console-baseline.json). Это доказательство роста вложенных функций, а не утечки DOM-слушателей. Причина различия частоты на конкретном телефоне пользователя отдельно не установлена; VPN не изменялся.

## Исправление и защита

Исправление SFX/comic 1.9.3 проверено: comic подключается до временного перехвата SFX; перехват отмечен `citadelSfxScope`, comic его не оборачивает. Основное исправление устраняет рекурсию; перехват исключений используется только для диагностики непредвиденных отказов.

Новый runtime: один владелец RAF, отмена старых callback по поколению, журнал до 64 событий и 3 ошибок (стадия, имя модуля, координаты стека, безопасные числовые поля состояния). Проверка разрыва кадров раз в секунду, порог 4 с; скрытая вкладка исключается. Потерянный callback восстанавливается с паузой. Ошибка рендеринга допускает одну попытку перерисовать паузу; повторная ошибка останавливает цикл. **Прерванный update не повторяется**, поэтому не дублируются начисления и события. Асинхронно восстановленный новый экземпляр игры может начать цикл.

Последний исправный checkpoint с интервалом до 5 с активной работы сохраняется отдельно в `cmpon.citadel.recovery.v1`, в прежнем формате `cupPack`; при отказе localStorage остаётся в памяти. Отдельные кнопки скачивают диагностику и резервную копию. Диагностика не содержит имени, токена, ответов, произвольного сообщения исключения или сохранения. Новый модуль ничего не отправляет в сеть. Резервная копия не подменяет турнирную очередь и автоматически не переигрывается. Потеря последних нескольких секунд при аварии возможна.

## Реальный браузер

Изолированный стенд [browser-qa.html](../browser-qa.html) загружает настоящую цепочку опубликованных скриптов. Тестовые сохранения хранятся в памяти, внешние запросы регистрации/результатов изолированы. Контроллер применяет игровые команды, прицеливание, движение, стрельбу и ответы, знает координаты и ключи ответов. Здоровье, боезапас, враги и статус победы не подменяются.

| Проверка | Результат | Измерение |
|---|---|---|
| Chrome, старые SFX/comic | Отказ воспроизведён | 2 537 шагов; 0 ожидающих RAF |
| Chrome, обычный темп | Без отказа, первый уровень | 196 с, 197 игровых вызовов; 57 слушателей; AudioContext running |
| Chrome, ручные карточка/озвучка/пауза | Без отказа на финальном runtime | 350 с наблюдения; 312 реальных вызовов arcadeInput, оператор отключён; см. manual-browser-notes.json |

Облачный Chrome использует медленный Canvas-режим (около одного отрисованного кадра в секунду). Ручные действия на финальном runtime: правильный ответ через DOM-кнопку, «Зачитать» (`recorded`, AudioContext running), возврат в бой, пауза и продолжение. На паузе время оставалось 1,8 с при продолжающейся отрисовке; после продолжения выросло до 5,96 с. При первом ручном DOM-взаимодействии счётчик глобальных слушателей однократно вырос с 57 до 70 и далее оставался 70; источник этого разового добавления не атрибутирован. В полном автоматическом прогоне он постоянно равен 57. См. `manual-browser-notes.json`.

Полные кампании в браузере используют **120 обычных шагов симуляции на один нативный кадр**; это проверка реальной JS/DOM/Canvas/Web Audio интеграции, а не замер FPS, ручное прохождение или полноценная проверка баланса. Обычный темп проверен отдельно. Полный обычный прогон использовал ранний runtime 1.9.3; спокойный — финальную сборку `193r2`. SFX/comic и игровая логика одинаковы. Сырые отчёты: `browser-*.json`. В раннем счётчике обычного браузерного прогона не учитывался ответ из вспомогательного контроллера погони; его 22 записи не используются как доказательство полного количества карточек. Учёт исправлен в стенде `193qa3`; программные кампании отдельно подтвердили все 23 карточки.

## Стресс и длительность

Структурный тест: **360 000 вызовов с dt=0**, 36 повторных подключений music/SFX/voice/comic, 84,4 с реального времени; 0 ошибок, 0 замен emit, слушатели 60→60. Heap после принудительной GC: 60,08–60,44 МБ. Нулевой dt проверяет рост обёрток и повторное подключение; это не 100 минут игрового прохождения.

Отдельный прогон с задержкой 16 мс между настоящими шагами, звук включён в логике, рендерер/аудиоустройство не заявляются: Завершены 2/2 кампании; суммарно 1742 с (29.0 мин) реального времени. normal: 901 с, 14/14 уровней, 50929 шагов, 23 карточки; слушатели 65→65, изменений emit 0; heap после GC 45.79–51.00 МБ. calm: 841 с, 14/14 уровней, 47575 шагов, 23 карточки; слушатели 65→65, изменений emit 0; heap после GC 45.80–50.76 МБ. 

Первый процесс между кампаниями встретил ENOENT: HTML уже получил параметр `?build=193r2`, а загруженная ранее версия тестового парсера ещё воспринимала его как часть имени файла. Обычная кампания к этому моменту полностью завершилась. Загрузчик исправлен, спокойная кампания запущена заново отдельной сессией; это отказ тестовой инфраструктуры до старта второй игры, не зависание движка. Суммарная длительность выше — сумма двух игровых сессий.

## Публикация и риски

GitHub Pages для кода завершился успешно: run `39183849886`. Опубликованные `index.html`, `atlas.html`, `version.json`, runtime, SFX и comic побайтно совпали с локальной сборкой: [public-assets.json](public-assets.json). Финальный коммит отчёта не меняет этот код.

Ограничения: компьютер/GPU пользователя, аппаратный WebGL, Safari/Firefox и физический телефон не подключены; потеря WebGL-контекста проверена моделированием. Звучание не оценивалось на слух; реальная загрузка 41 SFX-клипа, работа AudioContext и источник голоса `recorded` наблюдались, отмена/приоритет голоса подробно проверены моделированием. Закрытая админка показала вход ChatGPT, её UI не тестировался; доступные исходники использованы для дополнительных программных проверок. Контроль разрыва кадров требует работающей очереди JavaScript и не может самостоятельно исправить полную блокировку процесса браузера. Нет утверждения, что исключены все возможные причины зависаний на любом компьютере. Подтверждённая рекурсивная причина устранена, оставшиеся отказы теперь оставляют локальную диагностику.
