# Цитадель ЦСИИ 1.9.1 — доказательства публичного QA

Каталог содержит неизменённые JSON-отчёты, команды повторного запуска и SHA-256 проверенного среза файлов. Обозначения **Т01–Т13** соответствуют реестру доказательств технического и игрового разбора. Манифест привязывает результаты к содержимому файлов, а не к одному номеру версии.

Финальный публичный вход: **26 скриптов**, SHA-256 `index.html` — `8e08821d485df53bed1afa2a679aac0ce642f2c8b84c8fa726d567e278714cf3`. Обе кампании и проверка полного входа использовали именно этот состав. Полные прогоны завершились победой: **14 уровней и 23 карточки в каждом режиме**.

### Финальные и исторические доказательства

У независимого аудита ворот сохранён исходный SHA-256 модуля: `ada6bff0676dc2fef349dcbfbc8e9be4a3eae0d5724fa2846fbd069e6fc9b05a`. Финальные 28 групп палуб и сквозные кампании используют `c71aea261ff4ca22f6748be7bf3a167021cd3702dbe953192e6609eb1622c444`. Результат раннего аудита не приписывается финальному бинарному составу. Исходный скрипт независимого аудита и предфинальный срез являются внешними историческими материалами; финальные проверки палуб воспроизводятся по публичному сценарию ниже.

Исторический `campaign-calm-final.json` также сохраняет собственный список скриптов и их отпечатки. Финальный исправленный flight имеет SHA-256 `d8e345e6a7ef05ea3aebcb986042c1c36a809bb6608ccce242d00507178199b7`. Переносимый [навигационный сценарий](../flight-navigation191-regression.cjs) проверяет старый 1.8.1, оставшийся в `assets`, и новый 1.9.1 на одних игровых данных. Его PASS означает, что ожидаемый старый отказ воспроизведён, а исправленный сценарий завершён.

Фокусные проверки используют перечисленные в их исходниках цепочки модулей, в том числе некоторые прежние версии соседних модулей. Проверка точного `index.html` и две финальные кампании отдельно подтверждают актуальную полную интеграцию.

## Воспроизведение

Команды выполняются из корня `cmpon-atlas`. Новые результаты направляются в `/tmp`, чтобы архивные доказательства оставались неизменными.

Проверенная среда: **Node v24.19.0**, **@napi-rs/canvas 0.1.100**; отдельная Android-проверка использует ES5-парсер `next/dist/compiled/acorn` из **Next 16.3.4**. Это версии фактического стенда, а не обещание минимально допустимых версий. Зависимости должны быть доступны через `node_modules` или используемые тестами пути поиска среды.

Публичная интеграция, запуск и изолированные проверки публичного ядра:

```bash
node tests/mission-integration-regression-1.9.1.cjs --report /tmp/citadel191-entry.json
node tests/android-startup-regression.cjs --report /tmp/citadel191-android.json
node tests/decks-regression.cjs --core assets/atlas-v1.3.5.js --report /tmp/citadel191-decks-public.json
node tests/docking-regression.cjs --core assets/atlas-v1.3.5.js --report /tmp/citadel191-docking-public.json
node tests/recorded-combat-audio-regression.cjs --core assets/atlas-v1.3.5.js --report /tmp/citadel191-audio-public.json
```

Полная кампания использует два QA-контроллера из соседнего репозитория `cmpon-analytics-admin`: `scripts/mission-controllers.cjs` и `scripts/mrg-controller.cjs`. Двухъядерные профили дополнительно требуют его замороженный `game-lab/engine-v1.2.1.js`. Эти зависимости описаны контрольными суммами в манифесте; для запуска нужен доступ к соответствующему стенду. Публичная проверка точного входа обходится публичными исходниками и Canvas. Подмены DOM, сети и Web Audio уже находятся в публичных test helpers; входные файлы из `/tmp` не требуются.

Полный объём исходных кампаний и двухъядерных профилей в подготовленном стенде:

```bash
node tests/campaign-playthrough-1.9.1.cjs --report /tmp/citadel191-normal.json
node tests/campaign-playthrough-1.9.1.cjs --calm --report /tmp/citadel191-calm.json
node tests/flight-navigation191-regression.cjs --report /tmp/citadel191-navigation.json
node tests/docking-regression.cjs --report /tmp/citadel191-docking.json
node tests/decks-regression.cjs --report /tmp/citadel191-decks.json
node tests/recorded-combat-audio-regression.cjs --report /tmp/citadel191-audio.json
node tests/touch-input-regression.cjs --report /tmp/citadel191-touch.json
```

У навигационного CLI отсутствует `--core`; он проверяет оба ядра. Экспорт `verify(core)` позволяет выполнить только публичную часть, с меньшим объёмом результата:

```bash
node -e "require('./tests/flight-navigation191-regression.cjs').verify(require('node:path').resolve('assets/atlas-v1.3.5.js')).then(r=>console.log(JSON.stringify(r,null,2))).catch(e=>{console.error(e);process.exitCode=1})"
```

## Границы выводов

- Node VM исполняет настоящий JavaScript движка. Native Canvas проверяет программную отрисовку; подмены DOM не являются браузерной системой CSS-компоновки.
- Профили отсутствующих API, отказа GPU, закрытого хранилища и недоступного аудио проверяют предусмотренные программные пути. Они не означают запуск на физическом Android, проверку WebView конкретного производителя или приемлемый FPS на слабом устройстве.
- Аудиопроверки подтверждают маршрутизацию, события, очередность и отмену операций. В них подменены сеть, декодирование и Web Audio; качество звучания, баланс громкости, задержка динамика и естественность голоса требуют прослушивания.
- Автооператор знает точные позиции и правильные ответы. Полные кампании и палубные прохождения используют обычные игровые действия без выдачи ресурсов и удаления врагов. Это доказательство достижимости финала, а не оценка человеческой сложности или усвоения учебного материала. Время симуляции не включает человеческое чтение карточек.
- Независимый ранний gate-аудит применяет специально подготовленные состояния; его результаты отделены от прохождений обычными вводами.
- Абсолютные пути и имена необязательных PNG внутри исходных JSON сохранены как метаданные места запуска. Переносимые ссылки и команды приведены в этом README. Крупные изображения, аудиоданные и приватные журналы сборки не входят в каталог.

## Целостность пакета

[sha256-manifest.json](sha256-manifest.json) перечисляет все вложенные файлы кроме самого себя, публичные входы, все 26 активных скриптов и связанные публичные сценарии/фикстуры. Для каждого файла указаны относительный путь, размер и SHA-256. Приватные зависимости перечислены отдельно как метаданные; они не входят в проверку доступности публичного пакета.

Проверка JSON, размеров и контрольных сумм из корня репозитория:

```bash
node <<'NODE'
const fs = require('node:fs'), path = require('node:path');
const crypto = require('node:crypto'), assert = require('node:assert/strict');
const base = path.resolve('tests/qa-1.9.1');
const manifest = JSON.parse(fs.readFileSync(path.join(base, 'sha256-manifest.json')));
const files = [...manifest.files, ...manifest.entries, ...manifest.activeModules, ...manifest.references];
for (const item of files) {
  const file = path.resolve(base, item.path), bytes = fs.readFileSync(file);
  assert.equal(bytes.length, item.bytes, item.path + ': size');
  assert.equal(crypto.createHash('sha256').update(bytes).digest('hex'), item.sha256, item.path + ': SHA-256');
  if (item.path.endsWith('.json')) JSON.parse(bytes);
}
console.log('PASS: ' + files.length + ' files');
NODE
```

После изменения активных файлов контрольные суммы этого среза закономерно перестанут совпадать. Для проверки релиза следует использовать соответствующее состояние репозитория.
