# Бесплатная озвучка и радио 2.7.0

Дата: 22 октября 2026 года.

Готово **76 новых MP3** общей длительностью **488,42 с** и размером **3 950 095 байт**. Из них **74 синтезированы бесплатно локально** на CPU через Silero v5_cis_base; две ранее подготовленные записи сохранены. Модель обработала 74 реплики за 39,85 с на текущем хосте. Это время сборки, не показатель производительности телефона.

В игре теперь предусмотрены штурман, бортинженер, оператор связи, старший конвоя и два тембра перехваченных каналов. Старый капитан и все 110 прежних аудиофайлов сохранены; проверены их SHA-256. Клонирования голоса нет.

## Выбор бесплатного варианта

Проверены первичные источники:

| Вариант | Что установлено | Решение |
|---|---|---|
| [Silero v5_cis_base](https://github.com/snakers4/silero-models#v5-cis-base-models) | Официально MIT; русский язык; локальный CPU; открытый файл модели. Русскому тексту нужны явные ударения. | Использован. Подготовлены ударения для всех 74 текстов; модель проверена SHA-256. |
| [Piper](https://github.com/OHF-Voice/piper1-gpl) | Локальный синтез; русский Denis/Dmitri; карточки указывают CC0-датасеты, но открыт [вопрос о Lessac-инициализации](https://github.com/OHF-Voice/piper1-gpl/issues/314). | В этот набор не включён; уже найден вариант с явной MIT-лицензией модели. |
| [RHVoice](https://github.com/RHVoice/RHVoice) | Открытый локальный синтезатор русского языка. | Резервный вариант; для текущего выпуска нейросетевая Silero уже реально сгенерировала весь набор. |

Платные API не вызывались для этих 74 записей, аккаунты и подписки не менялись. Модель, PyTorch и промежуточные WAV **не входят в сайт**. Игрок получает только MP3 с того же домена, что и игра. Поэтому отсутствие русского системного голоса, лимит чужого TTS-сервиса или его недоступность не блокируют новые реплики.

## Проверки

- `audio270-regression.cjs`: **30/30 PASS**.
- Сопоставимые разрешённые окна 600 с во всех семи типах миссий: **35 стартов против 11**, отношение **3,18×**. Результат одинаков при наличии и отсутствии русского системного TTS: весь новый банк записан.
- Между репликами минимум 3,2 с. Занятость эфира 34–38%; одновременно максимум один говорящий. Учебное объяснение прерывает фоновое радио.
- Пауза, скрытие вкладки, смена движка, mute, выключение голоса отменяют текущее и запоздалое воспроизведение. Повторная загрузка/удаление модуля не наращивает обработчики.
- Часовой VM-стресс с переключением контекстов: **215 стартов**, один говорящий, максимум один таймер, **5→5 обработчиков**, кэш не превышает **12 МиБ**.
- `audio-complete-bank.json`: **76/76** новых записей выбираются по точной реплике; системных произнесений **0**, кэш ограничен.
- Все MP3 реально декодированы ffmpeg во время построения; измерены SHA-256, размер, длительность, RMS и пик. Отдельный независимый verifier повторно проверяет декодирование и аудиопротокол.

Это проверки файлов и протокольная симуляция аудиоплеера, а не физический Android и не прослушивание всех реплик человеком. Естественность шуток и актёрской подачи остаётся субъективной. Открытая модель не выдаётся за профессиональную студийную запись.

Фактические данные: `audio-local-generation.json`, `audio-regression.json`, `audio-complete-bank.json`, `verifier-radio.json`; полный набор и воспроизведение сборки описаны в `assets/voice-v2.7.0/README.md`.
