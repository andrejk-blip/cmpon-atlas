# QA баз 2.7.0

Проверены пять свежих высадок в боевом и спокойном режимах. Все 10 проходов завершены обычными командами движения, прицеливания, огня и импульса. Собраны 30 наград, пройдены 30 учебных карточек, использованы все 12 доступных пультов. Ответы выбирал программный оператор из настоящего банка карточек; это проверка переходов, а не оценка обучения человека.

## Изменения

- Первая база сохраняет вводную геометрию и состав противников.
- Со второй базы появляются наземные робопсы: заход с двух флангов, фиксируемое направление рывка и окно восстановления. Количество по базам: 0 / 4 / 6 / 7 / 8.
- На последнем секторе каждой продвинутой базы стоит мех: 495 / 580 / 665 / 750 единиц здоровья в боевом режиме, фронтальная броня, два лазера с фиксированным направлением начала прохода, уязвимое охлаждение. Скорость смены позиции возрастает от 7.5 до 9 м/с.
- Базы различаются планировкой: сборочные линии и реактор; силовые полосы и пульты; мостик и подъёмная платформа; финальная база с огнём, настоящими проломами и двумя платформами. Существуют проходимые обходы без обязательной поездки на платформе.
- Сохранённая активная база предыдущей версии остаётся прежней. Новая геометрия создаётся только при следующей высадке.

## Программное прохождение

Оператор принимает решения раз в 0.2 секунды. Боевой режим — обычные команды; спокойный — через адаптер экранного джойстика. Это Node VM, без браузера и реального телефона. В боевом прогоне не менялись здоровье, боеприпасы, урон, состав противников или признаки завершения. Начальная точка каждого прохода — тестовое сохранение перед свежей высадкой.

| Уровень | Время, с: боевой / спокойный | Минимум щита: боевой / спокойный | Карточки / награды в каждом режиме |
|---|---:|---:|---:|
| 2 | 73.22 / 71.07 | 71.00 / 93.40 | 3 / 3 |
| 5 | 107.90 / 106.15 | 67.01 / 96.08 | 3 / 3 |
| 8 | 102.70 / 95.33 | 46.10 / 87.52 | 3 / 3 |
| 11 | 87.53 / 79.05 | 39.53 / 96.34 | 3 / 3 |
| 13 | 106.80 / 101.62 | 45.47 / 96.74 | 3 / 3 |

Всего 931.37 секунд игровой симуляции. Основной набор: **6/6 PASS**, механические контракты: **7/7 PASS**. После перехода с 13-го уровня начинается МРГ; этот отчёт не считает его пройденным.

Дополнительно подтверждены: точное восстановление платформы в движении, отсутствие изменений во время паузы, 40 повторных подключений модуля без новых обёрток и обработчиков (68 обработчиков), одиночное обновление AI роботов, сохранение старой активной базы. В отдельной изолированной проверке мех действительно прошёл 6.75 м за 0.75 с со скоростью 9 м/с после 1.58 с охлаждения, без лучей во время перебежки. Изолированные проверки явно обозначают начальную расстановку и исключение посторонних врагов; они не выдаются за прохождение.

## Ошибки, обнаруженные до выпуска

1. Маршрут после прибытия платформы мог снова выбрать её, хотя повторная посадка заблокирована. A* исключает недоступный переход и выбирает наружный мостик.
2. Боковой проход через площадку автоматически увозил игрока. Теперь для посадки нужен шаг в направлении пролома либо остановка на площадке на 0.3 с. Самопроизвольного обратного рейса нет.
3. Программный оператор с реакцией 0.2 с колебался возле площадки и не останавливался. Исправлена именно команда оператора; это не было зависанием игрового цикла.
4. Тестовая админка не подключает сериализатор пользовательских сохранений. Модуль теперь проверяет его наличие и загружается в этом окружении без подставного хранилища.

## Границы вывода

Эти проверки доказывают достижимость целей и целостность симуляции на указанных входах. Они не доказывают субъективную увлекательность, стабильные 60 FPS или работу на физическом Android. Нативный рендер, браузерные проверки и полный поход учитываются в отдельных отчётах релиза. Историческое зависание версии 1.9.2 не приписывается найденным здесь ошибкам новой механики.

Данные: `base-missions.json`, `design-contracts.json`. Команды:

```sh
node tests/base270-regression.cjs --reaction=.2
node tests/base270-design-review.cjs
```
