# Короткие вопросы по анализу — банк 2.7.0

Дата: 22 октября 2026 года. Файл: `assets/citadel-quiz-bank-v2.7.0.js`.

Подготовлены **84 самостоятельных вопроса**, по **6 на каждую из 14 ступеней сложности**. Каждый содержит одну постановку, четыре варианта, один правильный индекс, объяснение одним предложением и учебную подсказку. Темы: бизнес-анализ, системный анализ, данные, требования, заинтересованные стороны, API, приёмка и процессы.

У текущей кампании **23 точки с карточками**: уровни 1/2/4/5/7/8/10/11/13. Все **84 вопроса достижимы** в этих точках через разные seed. На полётных уровнях 1/4/7/10 обе карточки выбираются из соответствующего tier. На базах первые две карточки используют текущую ступень сложности, третья — следующую: **2/2/3, 5/5/6, 8/8/9, 11/11/12, 13/13/14**. Это вводит более сложную тему перед следующим вылетом без дополнительных остановок. В каждой кампании выбираются 23 разных ID.

`CITADEL_QUIZ_BANK` — только неизменяемые данные. Контракт: `{version, language, entries}`; запись: `{id, tier, tags, contexts, question, options, correct, explanation, hint}`. Контекст финальной базы уровня 13 — `base`; tiers 3/6/9/12/14 помечены `base` и исходной миссией, которую предваряют. Модуль не читает сохранения, не меняет здоровье, очки или старые развёрнутые кейсы.

## Редакторская проверка

Все вопросы написаны для игры, без копирования закрытых материалов проекта. Дистракторы отражают реальные ошибки: подмена цели технологией, принятие отсутствия ответа за отказ операции, применение устаревшего события, усреднение процентов без весов, приёмка по числу строк, оценка эффекта по числу поставленных функций.

После первого черновика заменён 141 слабый отвлекающий вариант. Независимый редактор перечитал 84/84 записи; последующая точечная правка сняла неоднозначности пагинации, нагрузочного теста, проверки прав, единственного исполнителя и компенсации, уточнила язык и усилила поздние варианты. Вопрос о повторах отдельно требует уменьшить синхронность и ограничить число попыток: одного увеличения паузы недостаточно для обоих условий. В поздних уровнях сопоставляются решения одной предметной области. Нет вариантов «всё перечисленное» или подколов; по результату редакторской проверки у каждого вопроса один правильный ответ. Правильный вариант строго длиннее остальных в **27 из 84** вопросов; выбирать всегда самую длинную строку недостаточно.

Числовые вопросы проверены отдельно. Для возраста 18–65 включительно только набор 17/18/65/66 содержит обе внутренние и обе внешние граничные точки. В вопросе об общей доле отделы обработали 8/10 и 12/30 заявок: сумма **20/40 = 50%**. Среднее двух процентов, 60%, — осмысленный неверный вариант. Вычисления проверяет валидатор.
