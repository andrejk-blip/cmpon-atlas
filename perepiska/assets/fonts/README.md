# Onest

Local UI family for «Переписка». Variable weight range: 100–900; regular style.

- Source: https://github.com/google/fonts/tree/main/ofl/onest
- Original file: `Onest[wght].ttf` (193056 bytes).
- Original Git blob SHA: `477cb31027450d80e486a53119641bf87dde3d4c`.
- License: SIL Open Font License 1.1; included as `Onest-OFL.txt`.
- Local delivery: `onest-variable.woff` (108028 bytes), lossless fontTools WOFF packaging of the original font. No glyphs or outlines were changed.
- Original TTF retained in `assets/source/fonts/Onest-Variable.ttf`; excluded from the deployed build by the existing source-assets rule.

The full font is included, with Cyrillic, Ё/ё, Latin, punctuation and numeric glyphs. The interface uses `font-display: swap`; there is no runtime request to a font CDN.
