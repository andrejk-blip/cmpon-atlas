# Музыка первого дня

Три оригинальные инструментальные композиции для «Переписки». Мелодии, гармония, партии и вариации записаны в `scripts/compose-soundtrack.py`; готовые песни и чужие MIDI не использованы. Звук акустических инструментов получен из библиотеки сэмплов FluidR3Mono GM под MIT. Это программно исполненная музыка, без записи живых музыкантов.

| Файл | Композиция и настроение | Инструменты | Темп / размер | Петля |
| --- | --- | --- | --- | --- |
| `assets/audio/music/morning.mp3` | «Окно на Лесную»: спокойное утро, предвкушение первого дня | Мягкое фортепиано, нейлоновая гитара, контрабас | 88 BPM, 4/4, 32 такта | 87.272721088 с, 3 848 727 сэмплов |
| `assets/audio/music/courtyard.mp3` | «Знакомые окна»: любопытство, люди и движение во дворе | Флейта, нейлоновая гитара, электропиано, контрабас, тихая перкуссия | 96 BPM, 4/4, 32 такта | 80 с, 3 528 000 сэмплов |
| `assets/audio/music/evening.mp3` | «После смены»: тёплый вечер и личные разговоры | Электропиано Rhodes, нейлоновая гитара, контрабас | 76 BPM, 4/4, 24 такта | 75.789478458 с, 3 342 316 сэмплов |

Общий пятинотный мотив — ступени 2–3–5–3–1. У каждого трека свои ответы, тональность, гармонизация и ритм. Внутри пьес есть более редкие средние фразы, долгие ноты и паузы для диалогов. Аккорды сыграны с небольшим разносом нот; динамика и микротайминг меняются по фиксированному seed. Утреннее фортепиано смягчено исполнением и эквализацией: отдельной записи felt piano в библиотеке нет.

## Воспроизведение

Готовые файлы: MP3, stereo, 44 100 Hz, 160 kbit/s. Все три вместе занимают примерно 4.64 MiB. Измеренная интегральная громкость около −23.5 LUFS оставляет место шагам, интерфейсу и диалогам. Точные значения, размеры и SHA-256 находятся в `assets/audio/music/manifest.json`.

Для петли устанавливать `loopStart = 0`, `loopEnd` из manifest. Сэмплы указаны на канал. Прежде чем вырезать готовую петлю, генератор исполняет полный дополнительный круг, прогревая реверберацию и хвосты нот. В конце нет музыкального затухания или паузы. Только 128 сэмплов (2.9 мс) на обоих краях проходят косинусную коррекцию, устраняющую остаточный скачок фазы инструмента/реверберации; точная длина в тактах сохраняется. MP3 содержит Xing/LAME gapless metadata; при контрольном декодировании FFmpeg количество сэмплов совпадает с музыкальной петлёй.

Предпочтительный повтор в Web Audio — один декодированный `AudioBufferSourceNode` с `loop = true` и точной длиной. `sceneCrossfadeSeconds = 0.8` относится к переходу **между разными композициями**, например дом → двор. Перекрытие на 0.8 с при каждом повторе одной композиции сокращает музыкальную фразу и сбивает метр. Для декодеров без gapless поддержки следует убрать encoder delay/padding или использовать краткую коррекцию стыка до 10–20 мс; это проверяется на конкретной платформе. При диалоге уровень можно дополнительно плавно уменьшать, не перезапуская трек.

## Повторная сборка

Требуются Python 3 с NumPy, системная `libfluidsynth`, FFmpeg с `libmp3lame` и FluidR3Mono GM. CLI `fluidsynth` не нужен: скрипт обращается к библиотеке через ctypes. Проверено с Python 3.12.14, NumPy 2.3.5, FluidSynth 2.4.4 и FFmpeg 7.1.5. Партитура и вариации воспроизводимы; для побитовой идентичности рендера нужно также фиксировать версии библиотек и кодека.

```bash
python scripts/compose-soundtrack.py --soundfont /path/to/FluidR3Mono_GM.sf3
```

Можно задать путь через `PEREPISKA_SOUNDFONT`. Стандартный путь — `/usr/share/fluidr3mono-gm-soundfont/FluidR3Mono_GM.sf3`. Параметр `--track morning` / `--track courtyard` / `--track evening` пересобирает одну композицию и сохраняет metadata остальных. `--work-dir /path/to/temporary-render` оставляет промежуточные WAV для прослушивания и проверки; без него временные WAV удаляются после сборки.

Использованный build input:

- Debian `fluidr3mono-gm-soundfont`, версия `2.315-7`, файл `FluidR3Mono_GM.sf3`.
- [Исходный Debian-пакет](https://ftp.debian.org/debian/pool/main/f/fluidr3mono-gm-soundfont/fluidr3mono-gm-soundfont_2.315-7_all.deb).
- SHA-256 пакета: `4098301bf29f4253c2f5799a844f42dd4aa733d91a210071ad16d7757dea51d6`.
- SHA-256 SF3: `cda013d8c370a48ae8dad271e761078d2e77455488dabdedbfbe5fc76a38c682`.
- Seeds: morning `271828`, courtyard `314159`, evening `161803`.

## Проверка

Все MP3 полностью декодируются, имеют два канала, 44 100 Hz и 160 kbit/s. Число декодированных сэмплов проверено относительно длины тактов. Проверены отсутствие NaN/Inf и клиппинга, интегральная громкость, true peak, энергия в начале/конце и скачок на стыке. Manifest содержит измерения финальных MP3; поля `seamStepDbfs` и RMS описывают исходную PCM-петлю до MP3-кодирования. Эта техническая проверка не заменяет прослушивание баланса в самой игре на телефоне и в наушниках.
