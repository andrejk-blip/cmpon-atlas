# Возобновление работ после обрыва чата

Дата сверки: 23 октября 2026 года. Исходная точка: опубликованная 2.7.0,
коммит `5e057d5bca56fe3c16b15ebcb6cf9c3b26584e8d`.

Этот список относится к четырём последним запросам: три учебных режима,
горизонтальный телефон и запуск иконкой, усложнение роя, бесплатная озвучка.
Обрыв чата сам по себе не означает, что изменения не попали в релиз.
Сверка обнаружила код и отчёты по всем направлениям. Готовые механики
не переписываются повторно; ниже отдельно фиксируется свежая проверка.

## Последовательность

1. Зафиксировать эту сверку в Git, затем закрывать пункты в порядке таблицы.
2. Для каждого пункта сохранять команды, результаты и ограничения в
   `tests/qa-resume-2.7.0/`, а затем делать отдельный коммит.
3. Исправлять только воспроизводимые дефекты. Изменения игровых правил
   не выдавать за восстановление потерянной работы.
4. После последней проверки сверить опубликованные файлы с исходниками.

## Границы готовности

Симуляция обычных игровых команд проверяет правила и достижимость выхода;
она не равна ручному прохождению и не измеряет интересность. Эмуляция
размеров и сенсорного ввода в Chrome не заменяет Android/iPhone.
Установка на физическом устройстве, субъективная сложность и прослушивание
всех реплик человеком остаются отдельными проверками. Веб-версия требует
интернета; APK/App Store в эту работу не входят.
