# Радио «Цитадели ЦСИИ» 2.7.0

Весь новый банк — 76 готовых MP3: 74 реплики бесплатно синтезированы локально, две ранее подготовленные записи сохранены без изменения. Прежний банк из 110 записей, включая голос капитана и учебные объяснения, не перезаписывался.

Новые голоса принадлежат штурману, бортинженеру, оператору связи, старшему конвоя и двум перехваченным каналам противника. Подпись в радио соответствует роли; старый голос капитана не имитируется и не клонируется.

## Источник и воспроизведение

Использована открытая модель **Silero v5_cis_base**, выпущенная разработчиком под MIT. Лицензия сохранена рядом в `LICENSE-Silero.txt`. Ударения для всех многосложных слов заданы явно в `scripts/radio270-stressed.txt` и сверяются с исходным текстом. Файлы нормализованы, слегка обработаны как радио и закодированы в mono MP3 64 кбит/с. В `manifest.json` указаны фактические длительности, размеры и SHA-256.

- Официальный проект и описание лицензии семейства: https://github.com/snakers4/silero-models#v5-cis-base-models
- Лицензия: https://github.com/snakers4/silero-models/blob/master/LICENSE_CIS
- Модель: https://models.silero.ai/models/tts/ru/v5_cis_base.pt
- SHA-256 модели: `ba41b18f6a707ad93605a162998865e7c087153d2e010a26dd02229dab0e672a`

Модель, PyTorch и временные WAV находятся только на машине сборки. Браузер загружает нужный MP3 с сайта игры. Русский системный голос и доступ к внешнему сервису озвучки для этих 76 реплик не нужны. Кэш декодированного звука ограничен 24 клипами и 12 МиБ; одновременно звучит одна реплика. Учебная карточка имеет приоритет, пауза и уход со страницы отменяют звук.

## Повторная сборка

Создайте отдельное Python-окружение с CPU PyTorch, NumPy и SciPy; также нужны Node.js и ffmpeg. На исходной сборке использовались PyTorch 2.14.1+cpu и Python 3.11. Внешний сервис синтеза, платный аккаунт, API-ключ или видеокарта не требуются.

```sh
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install numpy scipy
python scripts/build-radio-pack-v2.7.0.py --model /tmp/citadel-tts/v5_cis_base.pt --workdir /tmp/citadel-tts/wav --download-model
node tests/audio270-regression.cjs
node tests/release270-radio-verifier.cjs --entry=tests/entry-2.7.0.html
```

Скрипт проверяет модель по SHA-256, не трогает прежние 110 файлов и сохраняет два существующих MP3 из раннего этапа 2.7. Остальные 74 файла воспроизводятся из русских текстов. Две сохранённые записи: Runway / eleven_v3, публичные пресеты Bernard и Clint. Клонирование чужих голосов не использовалось.

## Границы проверки

Декодирование, длительность, отсутствие клиппинга, объём файлов, выбор нужного клипа, частота старта, пауза и отсутствие наложений проверяются автоматически. Проверка тембра и естественности всей актёрской подачи на слух этим не заменяется. Локальная модель даёт больше разнообразия без зависимости от лимита облачного сервиса; это не новая студийная запись актёров.
